═══════════════════════════════════════════════════════════════════════════════
  COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

ISSUE 1: "Payment page is blank"
---------------------------------
Solution:
- Press F12 to open browser console
- Look for errors in red
- Common: "Razorpay is not defined"
- Fix: Clear cache (Ctrl+Shift+Delete) and reload

ISSUE 2: "PAY NOW button does nothing"
---------------------------------------
Solution:
- Open browser console (F12)
- Click button
- Check for JavaScript errors
- Most likely: Script not loaded
- Fix: Reload page

ISSUE 3: "Can't create booking"
--------------------------------
Solution:
- Check if seats are available
- Try a different date/time
- Make sure zone has seats
