🔑 ENVIRONMENT VARIABLES YOU'LL NEED
═══════════════════════════════════════════════════════════════════════════════

When deploying, set these in your hosting platform:

REQUIRED:
  • SECRET_KEY (generate random 50 characters)
  • DEBUG=False
  • ALLOWED_HOSTS (your domain)
  • EMAIL_HOST_USER (your Gmail)
  • EMAIL_HOST_PASSWORD (Gmail app password)
  • RAZORPAY_KEY_ID (from Razorpay dashboard)
  • RAZORPAY_KEY_SECRET (from Razorpay dashboard)
  • UPI_ID (your UPI payment ID)
  • UPI_PHONE (your business phone)

Complete list in: .env.production

How to get these values:
  1. SECRET_KEY: Run python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
  2. EMAIL_HOST_PASSWORD: https://myaccount.google.com/apppasswords
  3. RAZORPAY keys: https://dashboard.razorpay.com/app/keys

2. GITHUB
   git init
   git add .
   git commit -m "Deploy Gammers Adda"
   git remote add origin YOUR_REPO_URL
   git push -u origin main

3. DEPLOY
   • Go to hosting platform (Railway/Render)
   • Connect GitHub repository
   • Add environment variables
   • Deploy!

4. POST-DEPLOY
   • Create superuser
   • Add initial data (zones, games, pricing)
   • Test booking flow
   • Test payment (use: success@razorpay)
   • Verify email notifications

5. GO LIVE
   • Switch Razorpay to LIVE keys
   • Update domain in ALLOWED_HOSTS
   • Share URL with customers
